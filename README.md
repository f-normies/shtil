# Штиль

Ассистент врача для ведения пациентов с тревожно-депрессивной симптоматикой. Два кабинета: врача (компьютер) и пациента (PWA на телефоне). Решение команды ДОГМА.БИО для кейс-чемпионата «Клинический компас», октябрь 2026.

Все данные в репозитории синтетические.

## Что внутри

| Путь | Что |
|---|---|
| `apps/api` | бэкенд: FastAPI, модульный монолит и worker очереди на Postgres |
| `apps/doctor` | кабинет врача: Vite, React, TypeScript |
| `apps/patient` | кабинет пациента, PWA |
| `packages/ui`, `packages/api-client` | общие компоненты и клиент API, сгенерированный из OpenAPI |
| `knowledge/` | клиническое содержание как данные: шкалы, пороги, правила сигналов, препараты, источники |
| `services/asr` | сервис распознавания речи (GigaAM-v3 в sherpa-onnx) |
| `infra/` | образы web, Prometheus, Grafana и моделей |
| `eval/` | эталонные наборы и скрипты оценки AI: RAG, разбор дневника, извлечение из историй болезни, ASR |
| `e2e/` | сквозной тест в браузере |
| `loadtest/` | нагрузочный тест на Locust |
| `compose.yaml` | весь стенд на одной машине |

## Как запустить

Коротко:

```bash
cp .env.example .env      # заполнить строки с <...>
make stand-up-gpu         # приложение и модели; без GPU — make stand-up
make stand-seed           # демо-врачи и пациенты
```

Кабинет врача — http://localhost:8080/doctor/, вход `doctor@example.com` с паролем из `COMPASS_SEED_PASSWORD`. Кабинет пациента — http://localhost:8080/patient/, например `patient1@example.com` с тем же паролем.

## Ограничения, о которых стоит знать

- Система ничего не назначает сама. Всё, что предлагает LLM или правило, врач подтверждает или отклоняет.
- Алерты по баллам шкал считают детерминированные правила из `knowledge/rules`. LLM разбирает свободный текст дневника и чата. Она может поднять сигнал, но не снять его.
- У каждого порога, правила и шкалы в `knowledge/` указан источник. Лицензии шкал — в их файлах.
- Без моделей приложение работает: шкалы, алерты, чат, дневник. Не работают ответы по базе знаний, разбор свободного текста, расшифровка голоса и разбор документов.
