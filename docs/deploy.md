# Развёртывание

Всё поднимается одной командой на одной машине через Docker Compose. Домен, сертификаты и внешний прокси не нужны: кабинеты и API отдаются по HTTP на `localhost:8080`.

## Что нужно

- Linux x86_64, Docker Engine 24+ с Compose v2.
- Для моделей — NVIDIA GPU, драйвер и NVIDIA Container Toolkit. Сколько видеопамяти и почему — в [models.md](models.md).
- Без GPU стенд тоже поднимается, только без AI-функций (`make stand-up`).
- Процессор и память для приложения: 4 ядра и 8 ГБ хватает с запасом. На нашем стенде было 8 vCPU и 16 ГБ.
- Диск: около 10 ГБ под образы приложения и около 60 ГБ под модели и образы моделей.
- Для тестов и разработки дополнительно: [uv](https://docs.astral.sh/uv/), Node 24, pnpm 10.

Порты на хосте: 8080 — кабинеты и API, 3000 — Grafana (только 127.0.0.1). Оба меняются в `.env`.

## Секреты и настройки

```bash
cp .env.example .env
```

Заполните строки с `<...>`. Каждую можно сгенерировать командой из комментария рядом.

| Переменная | Что это |
|---|---|
| `POSTGRES_PASSWORD` | пароль Postgres. Тот же пароль подставьте в `COMPASS_DATABASE_URL`. |
| `S3_SECRET_KEY`, `COMPASS_S3_SECRET_KEY` | ключ хранилища RustFS для голосовых и документов. Значения одинаковые. |
| `COMPASS_THROTTLE_SECRET` | ключ HMAC для лимитов частоты входа, не короче 32 символов |
| `COMPASS_SEED_PASSWORD` | пароль всех демо-пользователей из `make stand-seed` |
| `GRAFANA_ADMIN_PASSWORD` | пароль admin в Grafana. Дашборд открывается и без входа. |
| `HF_TOKEN` | необязательно. Нужен, если Hugging Face ограничивает скачивание моделей. |

Пароли Postgres, RustFS и Grafana применяются при первом запуске, когда создаются тома. Чтобы сменить их потом, удалите тома: `docker compose down -v`. Вместе с томами удалятся и данные.

`COMPASS_*_URLS` уже указывают на сервисы моделей в compose. Если какую-то модель не поднимаете, оставьте её переменную пустой.

## Запуск

```bash
make stand-up-gpu      # или make stand-up без моделей
```

Что произойдёт:

1. Соберутся образы api, web, prometheus, grafana и образы моделей. llama.cpp с CUDA собирается 10–15 минут, если задан `CUDA_DOCKER_ARCH`, и 30–60 минут без него ([models.md](models.md)).
2. Модели скачаются в том `models` и проверятся по SHA-256, GGUF эмбеддингов соберётся из исходной модели. Это около 45 ГБ, один раз.
3. Поднимутся Postgres и RustFS, создастся бакет, применятся миграции.
4. Запустятся api, worker, web, Prometheus и Grafana.

`--wait` дожидается, пока все сервисы станут healthy. LLM грузится несколько минут.

Демо-данные:

```bash
make stand-seed
```

Сид создаёт двух врачей (`doctor@example.com`, `doctor2@example.com`) и восемь пациентов (`patient1@example.com` … `patient8@example.com`) с историей шкал. Повторный запуск ничего не дублирует.

## Проверка

```bash
curl -s localhost:8080/api/v1/health | python3 -m json.tool
```

В ответе `status: ok`. Раздел `inference` показывает, какие модели отвечают.

Дальше руками:

1. http://localhost:8080/doctor/ — войдите врачом, откройте список пациентов и сигналы.
2. В другом браузере или в окне инкогнито откройте http://localhost:8080/patient/ и войдите пациентом. Cookie у кабинетов общие, поэтому в одном окне сразу две роли не получится.
3. Пройдите у пациента PHQ-9 с ненулевым пунктом 9. У врача сигнал «Обязательно» появится сразу, без обновления страницы.
4. Дашборд быстродействия — http://127.0.0.1:3000.

## База знаний для ответов врачу

Ответы на вопросы врача (RAG) идут по индексу документов из `knowledge/sources`. Индекс строится один раз, нужны роли `embeddings` и `docparse`:

```bash
docker compose exec worker python -m clin_compass.cli index
```

Разбор PDF занимает около 30 секунд на страницу.

## Остановка и сброс

```bash
make stand-down              # остановить, данные остаются
docker compose down -v       # остановить и удалить все данные, включая модели
```

## Отличия от нашего стенда

- Наш стенд работал по HTTPS со своим доменом. Здесь HTTP и `COMPASS_ENVIRONMENT=local`. Отличие одно: cookie сессии без флага `Secure`.
- У нас модели работали на двух Маках с Apple Silicon. Здесь те же модели запускаются на NVIDIA. Подробности — в [models.md](models.md).
