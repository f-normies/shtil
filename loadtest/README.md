# Нагрузочный тест

Locust: врачи и пациенты против локального стенда. Порядок запуска — [docs/loadtest.md](../docs/loadtest.md).

| Файл | Что |
|---|---|
| `locustfile.py` | сценарии врача и пациента, ступени нагрузки, замер доставки алерта |
| `session.py` | вход, запросы и WebSocket одного пользователя |
| `accounts.py` | учётные записи теста |
| `doctors.py` | создание врачей, выполняется внутри контейнера api |
| `prepare.py` | создание пациентов через API |
| `run.sh` | прогон со сбором CPU, памяти и состояния Postgres |
| `report.py` | таблица по ступеням и график |
| `Dockerfile` | образ генератора: Locust и клиент WebSocket |
