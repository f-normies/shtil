# Сервис ASR

GigaAM-v3 `e2e_rnnt` int8 в sherpa-onnx на процессоре. Превращает голосовую запись в текст с пунктуацией, числами цифрами и названиями препаратов по подсказкам. Эндпоинт — `POST /v1/audio/transcriptions`, порт 8002. Бэкенд ходит сюда из worker.

Запускается как сервис `asr` в `compose.yaml`. Модель и Silero VAD скачивает `fetch.sh` при сборке образа и сверяет по SHA-256 из `versions.env`.

Проверка из контейнера в сети стенда:

```bash
curl -F file=@note.webm -F hotwords=Авиандр http://asr:8002/v1/audio/transcriptions
# {"text":"Доктор, я принимаю Авиандр 50 мг утром…","duration":8.61}
```

## Что важно знать

- Модель рассчитана на фрагменты до 25 секунд. Длинную запись сервис режет Silero VAD: пауза 0,5 с, сегмент не длиннее 20 с, поля 0,3 с. Сегменты длиннее 20 с в сплошной речи он режет сам.
- Без подсказок beam search молча выбрасывает незнакомое название препарата, поэтому без `hotwords` работает greedy search. Подсказки — по одному слову, вес не выше 2,5.
- Память: около 0,7 ГБ после старта, до 1,5 ГБ на записи 10 минут.

Тесты: `make test SCOPE=asr`. Тесты на настоящей модели синтезируют речь командой macOS `say`, на Linux они пропускаются.
